Archiving Mechanism

How new versions get added without touching prior ones

This page and each version sub-page follow a fixed mechanism to ensure a new version is always an addition, never an overwrite:

01

Standalone sub-page

Each version gets its own page, named results-v{version}.html (e.g. results-v2.1.html); its content and URL are kept permanently and never removed or rewritten when a newer version ships.

02

Top-level nav registers in sync

The "Results" nav dropdown and this page's version-card list gain one new entry whenever a version ships; existing entries stay as-is — only the "Latest" badge moves to the new version.

03

Versions cross-reference each other

Each version page carries a version-tab bar at the top for jumping directly to sibling versions, making it easy to compare how architecture decisions and measured results evolved over time.
